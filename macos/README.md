# macOS 连接窗口（已退出首版主流程）

按用户最新决定，首版采用 Agent 主导安装与链接绑定，保留轻量 Figma 插件窗口。本目录保存已有开发原型，暂停扩展与打包交付；普通用户无需打开独立窗口、重复粘贴链接或理解依赖说明。当前主流程见 [首次任务](../docs/first-task.md)。以下内容仅记录历史实现与边界。

本目录提供 AppKit 原生连接窗口，调用现有固定会话的 `setup`、`serve` 和 `doctor`。源码构建产物尚未签名、公证或发布；仍需完整连接、退出、重开及故障验收，不能作为普通用户安装完成的声明。

## 构建

需要 macOS、Xcode Command Line Tools 和 Node.js 22+：

```sh
node macos/build.mjs /private/tmp/test_local_figma_app
```

输出目录必须全新。生成 `local-figma.app`，包含运行时代码白名单与原生启动器；不会复制本地会话、设计稿或运行证据，也不会安装到 Applications、创建登录启动项或启动桥接。

开发版打开后粘贴带有 `node-id` 的 Figma 链接，再点击“启动连接”。应用查找 `/opt/homebrew/bin/node` 或 `/usr/local/bin/node`；当前不包含 Node.js，也不自动下载安装依赖。首次仍需在 Figma 中手动导入应用定位的 `manifest.json` 并运行插件。

连接运行于应用子进程。关闭窗口保留应用和连接，点击 Dock 图标重新显示；显式退出时询问是否停止自己启动的进程。有准备、检查或已检测到的任务进行中时拒绝退出。异常结束、端口被占用或既有连接目标不同均保留现状，交给 Agent 核查，不终止其它进程、不重放任务。
