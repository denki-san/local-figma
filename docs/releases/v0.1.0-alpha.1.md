# local-figma v0.1.0-alpha.1

首个 GitHub 试用 Alpha，提供本机 Figma 编辑工具与五种任务引导入口。

## 包含什么

- 本机 CLI、桥接与 Figma Development Plugin；会话配对、中文连接状态、目标核对与故障诊断。
- Agent 主导安装与链接绑定，Figma 内轻量窗口；同一绑定范围内继续选择、对话和修改。
- 文字、字体、填充、布局、对齐、分布、实例创建、文字/布尔实例属性、已有颜色变量绑定及简单原型连接。
- 自动选区、已用组件/变量/字体/样式信息，以及最多三个只读参考区域推荐。
- 五种任务的引导入口：创建、精修、HTML 还原、网页转原生设计与交互原型。
- 修改前快照、结果读回、局部差异、PNG 导出与不确定任务防重放。

## 安装

准备 macOS、Node.js 22+、Figma Desktop 和可执行本地任务的 Agent。把目标 Figma 链接和需求发给 Agent，让它处理安装与连接；首次按提示导入并运行开发插件。

Release 提供 `figma-local-runtime-0.1.0-alpha.1.tgz`，Agent 可运行：

```sh
npm install -g ./figma-local-runtime-0.1.0-alpha.1.tgz
figma-local help
```

## 适用范围

本版面向单个 Figma 文件与一个写入 Agent。已有稿精修和新页面设计可结合目标画板、参考与截图逐步完成；Design to Code、Code to Design 和原型任务由 Agent 按页制作、对照与检查。

连接中断或任务超时时，先让 Agent 查看现有结果和 Figma 文档，再继续操作。共享定义等高风险修改需要你在插件中确认。具体安全边界见[安全说明](../../SECURITY.md)。
