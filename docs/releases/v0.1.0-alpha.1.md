# local-figma v0.1.0-alpha.1

首个 GitHub 试用 Alpha。用户已决定冻结首版范围、停止长时测试，完成快速回归后发布。本版提供实际可运行的本地编辑工具与公开示例；完整五场景上线门槛保留为后续验收目标。

## 包含什么

- 本机 CLI、桥接与 Figma Development Plugin；会话配对、中文连接状态、目标核对与故障诊断。
- Agent 主导安装与链接绑定，Figma 内轻量窗口；同一绑定范围内继续选择、对话和修改。
- 文字、字体、填充、布局、对齐、分布、实例创建、文字/布尔实例属性、已有颜色变量绑定及简单原型连接。
- 自动选区、已用组件/变量/字体/样式信息，以及最多三个只读参考区域推荐。
- 五场景工作流与公开合成 Dashboard 示例：创建、精修、HTML 导出复现、网页指标行还原为原生实例、交互原型。
- 修改前快照、结果读回、局部差异、PNG 导出与不确定任务防重放。

## 安装

准备 macOS、Figma Desktop 和可执行本地任务的 Agent。把目标 Figma 链接和需求发给 Agent，让它处理安装与连接；首次仍需按提示导入并运行开发插件。

Release 提供 `figma-local-runtime-0.1.0-alpha.1.tgz`，Agent 可运行：

```sh
npm install -g ./figma-local-runtime-0.1.0-alpha.1.tgz
figma-local help
```

运行依赖 Node.js 22+。本版不发布 npm，不提供已签名的 macOS 应用安装包。

## 本次验证

- 一轮完整自动回归：161 项，其中初次 160 项通过；发现并修复面板错误提示遗漏。
- 发布审查补齐实例属性与颜色变量操作的异步祖先范围检查；修复前局部用例复现，修复后相关 23 项全部通过。未重复整套回归。
- 原生设计、精修、固定桌面 HTML 和原型主路径已有真实 Figma/浏览器案例证据；实例文字和显隐覆盖另有独立读回与截图。
- 长时任务按用户要求在 75/100 次、约 6 小时停止，保留结果；不能视为 8 小时完整通过。
- 发布包排除会话凭证、私有原稿与本地验收记录。

## 已知限制

- 五场景尚未全部达到最终上线门槛。复杂 Code to Design 的 Auto Layout 与最终评分待补；HTML 以固定桌面案例为主，未宣称任意页面像素级一致。
- 新轻量面板、参考推荐和颜色变量入口有局部自动检查，真实桌面验收尚未全部完成。参考推荐使用有界名称匹配，10 个任务的自动命中率尚未验证。
- 睡眠/后台恢复、温启动延迟、有限历史保留、干净机器完整安装仍需后续完善。
- 只支持一个文件与单个写入 Agent；首次需链接。无全自动首次插件导入、完整文档回滚、多文件同步。
- 失败或断连时先检查现有结果与文档，不重放不确定脚本。高风险共享定义修改需要用户确认。
