# local-figma v0.1.0-alpha.4

This preview adds Auto Layout controls and Chinese/English support for the public Figma plugin UI.

## Changes

- Layout edits support horizontal, vertical, and free positioning; fixed, hug, and fill sizing; axis alignment; spacing; and padding on each side.
- Structured workflows can create, update, and verify Auto Layout properties. Text sizing loads the required fonts before editing.
- Layout edits include affected Auto Layout ancestors and siblings in their readback. Workflows reject edits that would reflow content outside the authorized scope before writing.
- Plugin buttons, target hints, connection/task states, settings, confirmations, workflow progress, and inactive pages share a Chinese/English catalog.
- Figma's public Plugin API does not expose a reliable UI-language field. The plugin uses the browser language: Chinese locales display Simplified Chinese; all other locales display English.
- Branding, page/layer names, task titles, and task content remain unchanged. Extensions can provide optional `disclosureI18n` translations; older extensions retain their original disclosure.

## Download and install

Requires macOS, Node.js 22+ with npm, and Figma Desktop. Download `figma-local-runtime-0.1.0-alpha.4.tgz` from the release assets. The Source code archives are not the installation package.

```sh
npm install -g ./figma-local-runtime-0.1.0-alpha.4.tgz
figma-local help
mkdir -p ~/figma-local-project
cd ~/figma-local-project
figma-local init '<Figma frame link containing node-id>'
figma-local connect
```

Import the printed manifest through Figma Desktop → Plugins → Development → Import plugin from manifest, then run Figma Local Runtime. Keep the connection terminal and plugin running.

For upgrades, inspect any running task, stop the old plugin and connection, install the new package, and restart both. Preserve `.figma-agent/` bindings and evidence.

## Verification

224 automated tests passed, including CLI/HTTP/plugin message integration and isolated offline package installation. Real Figma tests checked card, list, and form Auto Layout behavior with long content, adding/removing content, and resizing. Real plugin screenshots cover Chinese and English connected, processing, settings, confirmation, error, disconnected, and not-started states. English screenshots used an English browser-language override only in the generated test plugin copy. Both languages passed 340 px panel checks without horizontal overflow.

The package contains the general-purpose runtime and documentation. Temporary scripts, logs, screenshots, credentials, and local experimental extensions are excluded.
