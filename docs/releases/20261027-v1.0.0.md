# local-figma v1.0.0

The first stable release of the local Figma editing runtime for Agents.

## Included capabilities

- Read, edit, and preview native Figma layers through a local bridge and Development Plugin.
- Edit text, fills, fonts, Auto Layout, instances, and prototype connections.
- Run structured workflows with assertions, optional human checkpoints, and recovery records.
- Preserve before/after evidence and task results; uncertain operations are not automatically replayed.
- Chinese and English plugin UI, with background connection handling.

## Maintenance changes

- `figma-local --version`, `-v`, and `version` return the installed package name and version as JSON. `--help` and `-h` show the same help as `help`.
- Plugin confirmation explains that the Agent explicitly marked the operation as high risk. Agent guidance distinguishes ordinary edits, high-risk operations, automatic snapshot acknowledgements, and optional workflow review.
- Updated the development-only `fast-uri` dependency to a patched compatible version.
- Updated current installation instructions and release references to v1.0.0. Historical release notes remain available.

## Install or upgrade

Requires macOS, Node.js 22+ with npm, Figma Desktop, and edit access to the target file.

```sh
npm install -g ./20261027-figma-local-runtime-1.0.0.tgz
figma-local --version
figma-local --help
```

Before upgrading, inspect any running task, stop the old plugin and bridge, install the new package, and restart both. Preserve the existing `.figma-agent/` binding and evidence. Use the manifest path printed by the restarted bridge.

Normal scoped edits do not require a plugin approval click. Each explicitly declared high-risk operation does; the plugin displays the reason and scope. Workflow human review is optional and configured per step.
