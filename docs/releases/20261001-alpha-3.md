# local-figma v0.1.0-alpha.3

This preview adds verified, resumable multi-step design workflows and visible task progress in the Figma plugin.

- Plans declare targets, structured operations, machine-checkable assertions, and optional review checkpoints.
- Explicit capabilities distinguish static design from navigation, scrolling, overlays, and Smart Animate. A later plan can connect existing screens.
- Durable journals, request deduplication, and shared node markers support bounded recovery without blindly duplicating edits.
- The plugin displays the current step and the first failed assertion. Connect results retain previous/current reactions; connect replaces existing ON_CLICK handlers while preserving other triggers.
- Valid background plugin polling is recognized by diagnostics and task waiting.

## Download and install

Requires macOS, Node.js 22+ with npm, and Figma Desktop. Download `figma-local-runtime-0.1.0-alpha.3.tgz` from the assets below. No clone or build is needed; the Source code archives are not the installation package.

```sh
npm install -g ./figma-local-runtime-0.1.0-alpha.3.tgz
figma-local help
mkdir -p ~/figma-local-project
cd ~/figma-local-project
figma-local init '<Figma frame link containing node-id>'
figma-local connect
```

Import the printed manifest path through Figma Desktop → Plugins → Development → Import plugin from manifest, then run Figma Local Runtime. Keep the connection terminal and plugin running. Your Agent can then inspect and edit the bound target. See the README for the complete workflow.

For upgrades, inspect any running task, stop the old plugin and connection, install the new package, and restart both. Preserve `.figma-agent/` bindings and evidence.

## Verification

The workflow implementation passed 195 automated tests in a clean committed snapshot. Figma Desktop smoke tests verified static edits and node reuse, native navigation and Back, Smart Animate with easing, and overlay open/close. Release packaging is checked separately with an isolated offline installation.

The package contains the general-purpose runtime and documentation. Local experimental extensions, temporary scripts, test logs, and private design evidence are excluded. Machine assertions do not replace visual review; recovery is bounded rather than transactional.
