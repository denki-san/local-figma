# local-figma v0.1.0-alpha.2

This release adds an optional entry point for local extensions to the standard runtime. The existing connection, selection, editing, preview, and evidence workflows continue to work without a model API key or an extension. The release package contains only the general-purpose runtime; experimental provider-specific extensions are distributed separately.

The plugin settings page lets you select an extension, enter an API key in a masked field, enable or disable the extension, and clear the key. The key is stored only in a restricted local file, not in the system keychain. A successful setup means the configuration was saved; key validity is checked when the extension is called.

This release also fixes:

- Re-handshaking and collecting context after the bridge restarts, so a connection is not shown as ready without its context.
- Allowing read-only inspection while recovering an earlier task. After verifying the exact original target, the Agent can stop waiting while preserving the unknown status of the original result, avoiding duplicate execution.
- Rechecking the target page, Frame, binding scope, and locked state while fonts load asynchronously.
- Reading back solid-color writes with a tolerance to avoid false failures from floating-point precision.

## Install and upgrade

Download `figma-local-runtime-0.1.0-alpha.2.tgz` from this release and run:

```sh
npm install -g ./figma-local-runtime-0.1.0-alpha.2.tgz
```

First check any existing task, then stop the old plugin and bridge. Install the package, start the bridge, and run the plugin again to load the new code. Keep the bindings and evidence in `.figma-agent/`. Long-running sessions still require you to start the service and plugin; this release does not include a background installer.

Automated verification covers the CLI, loopback bridge, simulated Figma API, recovery, and offline installation. The settings page was also checked in a separate browser. Visual results and real clicks in Figma still need to be reviewed in the target design file.
