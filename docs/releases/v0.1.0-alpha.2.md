# local-figma v0.1.0-alpha.2

普通版新增可选本地扩展入口。原有连接、选择、编辑、预览和证据流程继续可用，无需模型密钥或扩展。发布包仅包含通用运行时；特定提供方的实验扩展独立分发。

插件设置页支持选择扩展、隐藏输入 API key、启用、禁用和清除密钥。密钥仅保存在本机的受限文件，未使用系统钥匙串；配置成功表示已保存，实际调用时验证有效性。

本版同时修复：

- 桥接重启后重新握手并采集上下文，避免显示连接成功但上下文缺失。
- 恢复旧任务时开放只读检查；精确核验原目标后可结束等待，保留原结果未知状态，防止重复执行。
- 字体异步加载期间再次核对目标所属页面、Frame、绑定范围与锁定状态。
- 纯色写入使用容差读回，避免浮点精度造成误报。

## 安装和升级

下载本 Release 的 `figma-local-runtime-0.1.0-alpha.2.tgz`，运行：

```sh
npm install -g ./figma-local-runtime-0.1.0-alpha.2.tgz
```

先核对已有任务，停止旧插件与桥接，再安装、启动桥接、重新运行插件以加载新代码。保留 `.figma-agent/` 中的绑定和证据。持久会话仍需用户启动服务与插件；本版未加入后台安装器。

自动化验证覆盖 CLI、回环桥接、模拟 Figma API、恢复和离线安装。设置页另经独立浏览器验证。实际 Figma 视觉效果和真实点击仍需在目标文档验收。
