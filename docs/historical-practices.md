# Figma CLI 历史使用经验汇编

整理日期：2026-09-17。用途：为开源版本提供可复用的操作经验、失败样本与验收依据。

## 范围与证据

本次检索覆盖可访问的历史记忆索引中 Figma、CLI、桥接相关条目，并查阅对应的原生原型制作、连接失败、窗口生命周期复盘，以及既有本地技能的操作与设计检查手册。本文只同步使用经验；具体项目文案、设计内容、截图、真实文件链接、节点标识、私人路径和凭证均不收录。

证据标签：

- **历史观察**：来自过去任务的成功或失败记录；当前版本仍需复测。
- **操作守则**：来自已固化的技能与使用复盘；属于执行和检查要求。
- **产品建议**：根据经验提出的开源实现方向；实现状态以 `implementation-status.md` 为准。

历史成功说明旧工作流具备可行性。当前开源代码的兼容性、覆盖范围和恢复能力需要独立验收。本文未重新操作真实 Figma 文件，也未逐条重新执行历史脚本。

## 一、安装、连接与生命周期

1. **历史观察**：服务已启动、插件已导入、插件已运行、插件已连接需要分别判断。安装流程应展示这些独立状态。
2. **历史观察**：Development 菜单可以残留同名旧插件。加载失败时先确认 manifest 所在目录仍存在、注册项指向本次生成的插件。
3. **历史观察**：插件环境加载错误可能来自 manifest 路径失效。应优先查看具体错误，避免反复提交设计脚本。
4. **历史观察**：`pollAgeMs: null` 表示尚未形成有效轮询连接。桥接端口可访问仍不足以允许写入。
5. **操作守则**：连接后先做小型只读探测，确认目标、节点与字体；探测通过后再扩大写入规模。
6. **操作守则**：服务重启会更换会话凭证，插件需要重新加载相应 UI。诊断信息应明确提示这一点。
7. **操作守则**：端口被占用时先识别占用者，或选择新端口并同步插件配置；保留未知进程。
8. **历史观察**：回环监听可能被执行环境拒绝。按平台机制申请局部权限，保留系统安全设置。
9. **操作守则**：插件窗口在任务期间保持打开。关闭前检查相关任务是否仍在执行，特别是其他 Agent 发起的任务。
10. **历史说明**：关闭桥接窗口会断开通信，已写入设计仍留在文档中；正在执行任务的最终状态需要读回确认。历史窗口咨询没有实际执行关闭测试。

## 二、目标绑定与权限边界

11. **操作守则**：文件、页面与节点标识来自当前授权目标；历史记录仅供定位线索，执行前重新校验。
12. **操作守则**：名称可重复，也可能被修改。名称用于帮助人辨认，身份校验需要结合稳定标识。
13. **操作守则**：每个任务的配置与凭证独立，通用模板使用参数，避免携带上次任务的目标。
14. **操作守则**：把文件名、页面名、节点用途与允许修改的范围一起交给 Agent，减少选对节点却改错语义的问题。
15. **操作守则**：用户选择本地 CLI 路线后保持执行渠道一致。缺少能力时列明缺失项和需要的授权。
16. **操作守则**：目标校验提供防误操作保护；可信本地 JavaScript 仍拥有插件环境允许的文档访问能力。
17. **操作守则**：设计稿文字、评论与外部参考均按数据处理，任何扩大执行范围的指令都应回到用户授权。
18. **产品建议**：将权限不足、目标错误、插件未连接、凭证过期分成独立错误，给出各自的恢复动作。

## 三、任务执行与结果判定

19. **历史观察**：提交返回 job ID 证明任务入队。随后读取同一 job 的 result，再检查成功状态与输出。
20. **操作守则**：区分已入队、已取出、执行中、脚本完成、文档读回、视觉通过、点击通过。
21. **操作守则**：每批聚焦一个区域或一组强关联节点，并返回新增与修改节点的映射。
22. **操作守则**：后续修改优先使用已经返回的节点 ID，减少重复创建和按名称误选。
23. **历史观察**：画板数量与完成数量可能不同。交付时分别统计空画板、已有内容、已有连线和已实点验证的范围。
24. **操作守则**：任务超时或结果丢失时先检查文档现状。请求重试与脚本重执行必须分开处理。
25. **操作守则**：创建脚本重放可能增加副本；补做前检查前一次运行的节点与结果。
26. **产品建议**：持久化运行标识、脚本 hash、节点映射与结果状态，为断连后的判断提供依据。
27. **产品建议**：区分结果回传失败与文档写入失败，状态无法确认时显式标记为待核验。

## 四、文字与布局易错点

28. **操作守则**：修改文字前加载所需字体。字体可用性以实际执行环境的枚举和加载结果为依据。
29. **历史观察**：桌面插件执行与浏览器字体提示可能不同，诊断时标明发生问题的环境。
30. **用户复盘**：单个 Text 节点也可能含混合字号、字重与行高。检查文本范围，保留有意设置的富文本。
31. **历史经验**：Auto Layout 的自动尺寸可能让标题行、按钮、标签收缩。需要固定宽度时同时明确 sizing 与尺寸，并读回验证。
32. **用户复盘**：截断、最大行数、文本 resizing 与外层 clip 需要组合检查。历史现象应转成回归样例，具体属性行为按当前运行环境复测。
33. **用户复盘**：圆形编号需要检查是否换行；字号正确仍可能受容器宽度、内边距和文本尺寸模式影响。
34. **用户复盘**：正文与底部标签需要一起截图检查，局部文字节点读回容易漏掉邻接覆盖。
35. **操作守则**：浮动控件检查首屏、中段和列表尾部。增加底部留白仍需验证首屏文字是否受遮挡。
36. **用户复盘**：固定滚动属性未生效时，可考虑独立滚动视口与外部固定区的同级结构；更改后仍要实际滚动验证。
37. **操作守则**：比例、圆角、间距等显式要求先数值读回，再看截图。历史项目中的具体数值只适用于原任务。
38. **操作守则**：图片加载与原型转场稳定后再判断布局，避免把中间态误判为最终效果。

## 五、原生图层与原型验收

39. **历史观察**：本地桥接曾产出可继续编辑的原生图层与原型连线。交付时抽查 Text、Frame、组件或实例的实际类型。
40. **操作守则**：照片与背景可以使用图片填充；文字与交互结构保留原生编辑能力。
41. **历史经验**：克隆画板可能复制原型起点。克隆状态页后重新核对页面的入口集合。
42. **操作守则**：展开、收起状态同步图标与内容；目的地需要匹配节点代表的层级和范围。
43. **操作守则**：共用目的地至少从两个来源实点返回，检查返回位置符合来源关系。
44. **操作守则**：reaction 存在证明连线属性已写入。真实点击另行验证目标、返回、滚动与遮挡。
45. **操作守则**：静态键盘、占位相机界面等示意状态明确标注范围，功能可用性留给真实产品验证。
46. **历史经验**：视觉与原型通过后，易理解性等用户研究结论仍需要真实测试。

## 六、上下文与从零设计

47. **用户复盘**：同时记录内容真源、摘要视图、完整内容与派生输出之间的关系，防止把展示区域误当作独立内容源。
48. **用户复盘**：完整内容展示使用完整真源，并单独核对内容完整性；视觉长度仅能作为辅助线索。
49. **操作守则**：先区分现有稿微调、保留功能的视觉探索、基于功能重新规划三种目标，再选择参考与保留边界。
50. **历史经验**：候选方案保留基线并突出明确的核心差异，便于用户理解选择依据。
51. **操作守则**：先做结构与组件，再补文字和图片，最后接原型。各阶段分别检查，减少整页返工。
52. **操作守则**：品牌标识优先复用用户授权资产；近似绘制的图标注明示意性质。
53. **用户复盘**：图层名表达用途、内容范围与布局角色，降低后续 Agent 重新理解的成本。
54. **历史经验**：多工作目录环境先定位真正的需求与设计真源，缺失相对路径时检查目录关系。
55. **产品建议**：从零设计先收集少量参考，并逐张记录希望借鉴的部分、需要避开的部分和素材使用权限。
56. **产品建议**：结构、视觉、业务、历史四层上下文独立存储，明确来源与更新时间，减少旧决定误用。

## 七、恢复、隐私与交接

57. **用户复盘**：替换时保留旧节点或隐藏旧版本，待用户确认后再清理；隐藏策略只提供恢复基础。
58. **操作守则**：保留脚本、节点映射与结果，便于判断哪些步骤完成、哪些需要补做。
59. **操作守则**：结束时仅关闭自己启动的桥接，并确认进程退出；保留用户原始素材。
60. **操作守则**：临时 session 与带凭证 UI 排除出日志和仓库；公开经验使用占位标识。
61. **历史观察**：旧工作流通过过认证、队列、结果落盘与凭证清理的回环模拟测试。模拟测试与真实 Figma 验收分别记录。
62. **历史边界**：旧桥接手册明确缺少事务、脚本隔离和自动恢复。开源版增加这些能力时，需要新的实现证据。
63. **产品建议**：Undo 与快照恢复需要检查当前文档是否被其他操作改变；恢复后再读回，确认预期内容恢复。
64. **产品建议**：交接固定记录目标、已完成步骤、已验证范围、剩余风险和下一步；只同步必要的脱敏信息。

## 八、经验迁移与版本复用

65. **历史经验**：将一次性流程固化为工具时，把目标配置与执行机制分开；每次生成独立配置，公开模板仅保留参数。
66. **历史边界**：一次真实任务成功与通用模板跨任务可用分别验收。首次复用先用小型只读探测或低风险修改。
67. **操作守则**：开发插件 UI 中的临时凭证跟随会话变化；归档前检查生成文件，避免只清理独立 session 文件却遗漏内嵌凭证。
68. **产品建议**：将历史成功步骤与当前命令建立映射，旧 CLI 命令保留为历史说明，快速开始仅展示当前可执行语法。
69. **产品建议**：经验条目携带证据类别和适用边界，公开版本使用合成回归场景复现失误，保留真实稿件在用户本地。
70. **产品建议**：接口合同需要对照实际产物测试；草案中的事务、恢复或确认字段单独归档，避免接入方推断尚未实现的保障。

以上新增条目延续原有脱敏范围；本次仅复核历史记忆与操作手册，真实 Figma 行为等待新版本实测。

## 对开源版本的落地优先级

以下是经验到产品的映射，所有新增能力均需查实现状态后使用。

| 优先级 | 经验来源 | 建议产物 | 验收依据 |
| --- | --- | --- | --- |
| P0 | 1–18 | 连接诊断、目标绑定、明确错误 | 错误 manifest、断连与错误目标均有可执行提示 |
| P0 | 19–27 | 持久化任务状态、只读恢复检查 | 丢失回包后可辨认现状，避免自动重复创建 |
| P0 | 28–46 | 局部预览、文字布局检查、点击清单 | 已知失误样例可复现，人工视觉检查单独记载 |
| P1 | 47–56 | 场景 brief、语义上下文、参考引导 | 能解释内容来源、设计依据与保留边界 |
| P1 | 57–64 | 脱敏导出、恢复保护、交接摘要 | 无私密信息泄露，恢复结果可读回验证 |
