# 首次真实桌面验收

日期：2026-09-17。环境：macOS、用户已登录的 Figma Desktop、当前本地 Alpha。该记录只包含使用经验与合成测试结论，真实文件标识、原设计正文和截图不进入公开文档。

## 已验证路径

1. 开发插件导入、真实心跳、file key 与页面 ID 校验。
2. 大页面目录读取及 `--node` 局部子树读取，保持插件连接。
3. 字体列表读取与 Noto Sans SC Regular/Medium 实际加载。
4. 独立测试画板内创建原生 Frame/Text、纵向 Auto Layout、按钮和三行文字截断。
5. run 前快照保存确认、结果持久化、结构 diff 与独立 PNG 导出。
6. 单个合成文字节点精确改写，diff 只记录 characters 变化。
7. 合成脚本在改写后主动抛错，保留 executionStarted=true、前后文字与 Undo 边界。
8. 新的 inspect 读回部分写入状态，恢复脚本核对精确目标与预期文字后恢复单字段；恢复后的已采集快照与故障前相等。

## 视觉检查

已查看原始导出 PNG：中文字体、三行省略、卡片与按钮间距、底部状态文字符合合成用例。恢复后再次导出，状态文字恢复到预期内容。图层保持可编辑。

自动 validate 仍返回 needs-review，视觉字段仍为 not-run；这里的截图评审记录独立保存，未伪造自动检查的覆盖能力。最初的“查看完整说明”按钮未配置跳转。

## 滚动与真实点击复测

- 在同一独立测试画板内追加 260 px 高的滚动视口，880 px 高的正文包含 12 条合成内容；操作栏是视口外的同级节点。
- 原型实际滚动：顶部第 1 条 → 末尾第 12 条 → 滚回第 1 条。上方摘要与固定操作栏保持原位置，最后一条可见且未被操作栏遮挡。
- 固定栏通过 setReactionsAsync 配置 SCROLL_TO，真实点击：滚到第 12 条后点击“回到正文顶部”，第 1 条重新出现。此结论来自桌面操作与前后截图观察，独立于 reactions 属性读回。
- 动态页面写 reactions 使用异步接口，依据 [Figma reactions 文档](https://developers.figma.com/docs/plugins/api/properties/nodes-reactions/)；动作类型见 [Action](https://developers.figma.com/docs/plugins/api/Action/)。
- 原型标签页位于前台时，后台编辑页心跳曾超时，提交被明确拒绝且没有任务 ID。返回编辑页后心跳恢复，无需重启；随后提交成功。该行为已进入诊断建议。
- 当前只验证同屏嵌套滚动和回顶点击；跨画板导航、返回来源、组件状态和移动设备手势仍待验证。

## 边界与异常处理

- 原页面顶层目录从 47 个节点增至 48 个，仅新增独立验收画板；原有 47 个顶层节点及已采集属性相同。该比较不证明未读取的深层属性完全一致。
- 初始化用一个未修改的小节点作为锚点，在同页新增独立画板；该任务快照只覆盖锚点。新增区域通过后续页面目录读回定位，之后所有写入都绑定新画板或其后代。范围外变更无法由局部 diff 自动证明。
- 首次初始化在 setPluginData 处失败，因为默认 manifest 未配置 Figma 分配的插件 ID；画板此前已经创建。处理方式为保留现场、重新 inspect、按返回 ID 继续，未重跑创建脚本。
- 本轮只证明一个真实文件中的局部编辑、嵌套滚动与回顶点击、单字段恢复。完整文档 rollback、三个不同文件迁移、更复杂原型、高风险用户确认、从零参考到成稿的用户方向选择尚未验收。

## 可复用经验

- 2026-09-19 大结果传输复测：复杂素材提取曾触发 Figma 插件运行时中止，控制台堆栈包含 `deepUnwrap`。大消息改走 JSON 字符串封装后，真实插件完整回传 40,000 项数字并逐项校验相等。后续一批素材超过 16 MB，按预期返回失败；该失败未计入成功导出。缩小图形尺寸并分批后，连续 16 批共 188 个小图形成功回传，无导出告警。这些证据证明本次消息和素材链路，未证明长时稳定性。
- 2026-09-19 Design to Code 局部进展：在原参考画板相同的 1920×1080 视口下检查本地 HTML，修正组合图层偏移、头像遮罩和零宽高分隔线；浏览器检查实际使用的 240 张图片全部加载。文字保留 DOM，头像及小图形采用图片素材。仍存在部分描边与图标方向差异，关键交互尚未完成，保留待验收状态，不声明 1:1 或 8 分。真实素材仅存放在本地忽略目录。

- 2026-09-19 自动选择与文字修改实测：插件连接后自动识别当前固定栏；隐藏面板并在图层列表选中「测试标题」后，上下文自动更新到所选文字及所属独立验收画板。通过高层文字命令提交中文新标题，无需传入节点 ID 或脚本；执行成功并读回新文字，桌面画布已目视确认。仅修改合成测试标题，原始参考画板保持不动。此案例验证当前选择到单字段修改链路，尚未构成已有稿精修全场景的 8 分验收。

- 2026-09-19 隐藏面板实测：在 Untitled 点击「隐藏面板」后，插件浮窗消失，Figma 显示插件仍在运行；随后通过本机 CLI 执行局部只读检查，结果成功回传且节点匹配。此次验证仅覆盖隐藏状态下的短时只读执行，未覆盖后台长时间节流、睡眠唤醒或 8 小时持续运行。

- 2026-09-19 复杂画板预览复测：原 1920×1080 参考画板因超过 2000 节点，导出 PNG 前的结构快照失败。预览改为根节点摘要后，真实插件成功导出完整 PNG，并已打开图片确认侧栏、任务卡片、工作说明抽屉及底部输入区可见。摘要保留 `truncated` 标记；写入仍要求完整快照。新增回归用例验证 2100 个子节点可预览、同一目标写入仍被拒绝。此结果仅证明参考截图路径，五场景成品验收继续保持待验证。

- 更新后的插件已实测超大结果处理：返回 17 MiB 合成字符串，保存约 64 KiB 失败证据，随后独立 inspect 成功。前后快照与独立读回一致，测试脚本未修改设计。深度截断拒绝当前仅有自动测试证据。

- 消息源对象假设必须通过真实宿主验证；健康心跳与结果回传分开检查。
- 大页面先获取浅层目录，再选节点执行完整读取与写入。
- API 能力在修改前核验；失败后先独立读回，创建脚本禁止直接重放。
- 单字段恢复需检查当前值，加载字体后再次复核，保留用户并发修改。
- 私有插件数据受插件身份限制，见 [Figma manifest](https://developers.figma.com/docs/plugins/manifest/) 与 [setPluginData](https://developers.figma.com/docs/plugins/api/properties/nodes-setplugindata/)。
