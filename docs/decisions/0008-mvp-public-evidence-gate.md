# ADR 0008：MVP 公开实证门槛

状态：已修订，2026-09-17 按用户要求收敛首版范围；以下旧门槛保留作历史记录，不再作为首版阻塞项。

## 当前决定

首版验证安装连接、已有稿局部精修、从零设计引导到成稿评审三条使用路径。保留失败后独立读回、不重放脚本、原生可编辑结果和视觉检查的质量要求。多文件迁移矩阵与完整文档恢复进入后续版本，当前能力与限制应如实公开。详见 [发布清单](../release-readiness.md)。

## Context

单一 Figma 文件或单一修改类型无法证明链接 binding、复杂布局处理和失败恢复具有可迁移性。

## Decision

MVP 公开前，至少在三个不同 Figma 文件分别完成并记录：

1. 局部文字修改。
2. 复杂布局修改。
3. 失败恢复。

三个案例共同证明：

- 首次目标来自用户 Figma URL，并锁定正确 file/page/node。
- 脚本、结构化结果和 evidence 完整保存。
- 超时或断连后先读回状态，不盲目重放。
- 最终状态可以通过结构读回、preview、validation 或 rollback 证据验证。

## Consequences

- 项目不能仅凭回环测试或一个成功案例宣布公开 MVP 达标。
- 失败恢复案例与成功修改案例同等重要。
- 案例 evidence 默认本地保存；公开时只提交脱敏材料。
