# ADR 0005：P0 用户与产品范围

状态：Superseded（历史决策，由[新 P0](../p0-scope.md)替代）

以下保留早期定位的决策背景。当前实施以新 P0 的一次安装连接、自然语言任务、高层操作和五场景验收为准；此历史文档中的安装取舍与成稿范围不再构成当前发布门槛。

## Context

个人 Agent 用户、普通设计师和团队设计系统维护者对安装体验、权限模型、风险说明与验证能力的需求差异很大。P0 需要一个唯一首要用户，避免同时扩张 CLI、插件分发、团队治理和自动设计能力。

## Decision

- P0 唯一首要用户是个人 Agent 用户；具体 Agent 产品不限。
- 任何能够调用 CLI、读取 JSON 和文件结果的 Agent 都可以集成。
- 用户已经能够使用命令行和 Agent，并愿意显式启动 Development Plugin。
- 核心 use case 是精确修改现有 Figma 稿，并保留原生可编辑图层、证据与恢复路径。
- P0 不服务普通设计师的零配置安装体验。
- P0 不提供 Hosted 服务。
- P0 不承诺自动从零生成高质量 UI。
- 设计工程师、团队设计系统和企业治理场景不进入 P0 产品承诺。

## Consequences

- 文档可以直接解释 CLI、脚本信任和插件生命周期，无需为非技术用户隐藏复杂度。
- P0 可以保持 CLI + Development Plugin 的显式连接合同。
- 视觉上下文和 design-system discovery 仍可研究，但不能扩大成自动设计承诺。
- 后续扩大用户群需要新的用户研究、安装流程和 ADR。
