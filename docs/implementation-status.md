## 已实现

- 零运行时依赖的 Node.js CLI 与本机 HTTP bridge。
- 从用户链接解析 file key、node ID，拒绝伪造域名与无目标链接。
- 生成 Development Plugin manifest、代码与临时认证 UI。
- CLI 与插件使用不同令牌，bridge 仅监听回环地址。
- inspect、preview、可信脚本函数体执行、任务查询与本地证据。
- inspect、preview、design-system 和 run 支持 --node 选择绑定范围内的节点；执行前与快照确认后校验祖先关系，目标范围与证据持久化在每个任务中。
- inspect 扩展布局、外观、截断、滚动、变量/样式引用和原型属性，并独立复制复合值；完整覆盖与限制见 inspect-coverage.md。validate 增加缺失字体和截断组合提示。
- 插件严格校验 file key；执行前后读取目标结构，异常后保留部分写入状态。
- 单个任务一次交付，禁止自动重放，拒绝并行写任务。
- 交付日志保存失败保留 queued；并发领取只允许一次交付。启动中途失败清理本次触及凭证，清理失败保留锁；重复 close 共用一次退出操作。
- 插件执行期间通过独立 heartbeat 路由保持连接；心跳不领取任务。请求超时后保留结果并重试回传，UI 校验结果属于当前任务。
- 同任务并发回传串行保存，首次已落盘结果保持不变；result 与任务日志都落盘后才释放写入门禁。日志保存失败时允许重试回传，并保留原结果。
- run 执行前保存 before.json 结构快照并等待 bridge 确认；失败或超时停止脚本。等待期间再次核对目标所属页和已采集属性，变化时停止。
- run 前后记录 commitUndo 边界，部分失败也保存边界状态；开始边界失败阻止脚本，结束边界失败保留原始错误与读回。尚未触发自动 Undo 或证明真实恢复。
- 提供授权测试副本使用的合成文字故障及恢复脚本，检查节点身份、预期内容和混合样式，字体加载后再次核对；真实单文件内已验证指定 characters 字段恢复，完整文档恢复仍待实现。
- design、refine、design-to-code、code-to-design、prototype 五种 brief 与操作指南。
- 两条合成 brief 示例与逐项视觉评审清单随包分发；示例保留用户方向选择，guide-check 拒绝空设计资源或保护区域条目。
- guide-check 根据场景检查真实内容、修改与保留范围、参考文件及借鉴说明、设计基础和方向确认，分别报告规划与执行准备度；只检查输入完整性。
- design-system 只读发现目标子树已引用的样式、变量、组件和字体，返回使用位置与解析警告；尚未提供相邻页检索或变量模式解析。已确认的同页本地主组件可通过 instance 命令复用，发现资源不等于自动决定来源。
- 离线 result/history，以及根据前后快照计算的目标子树 diff；快照缺失或截断时拒绝比较。
- wait 有界等待本地结果与终态日志一致；超时不停止或重投脚本，已有恢复提示提前返回待核验。已用真实桌面只读任务验证 completed。
- 只读 doctor：项目绑定、会话格式、锁记录、插件资源、实时认证、会话身份、轮询与未完成任务检查，输出不包含凭证。
- 显式 recover：仅在锁对应 PID 已退出时归档锁、清理旧凭证，为未完成任务补充核验提示；保留原任务日志且不重放脚本。
- 显式 --high-risk 声明支持插件 UI 允许/拒绝和确认记录，绑定脚本 hash；确认前禁止写入快照。自动风险分类和独立操作者身份验证尚未提供。
- 离线 validate：文字、命名、尺寸与裁切风险提示，缺失字段标明覆盖缺口；视觉、交互和用户验收独立保留为未执行。
- 当前 job/result/diff/validation 输出合同经 Ajv 对照贯通产物验证；旧协议移至 schemas/drafts，接入说明见 protocol.md。Ajv 仅用于开发测试。

## 当前限制

自动风险分类与文档 rollback 尚未实现，Alpha 仅适合可信、局部、可人工恢复的任务。高风险门禁依赖正确声明与用户审阅。原插件恢复心跳可续接；替换插件需等待旧租约过期，在途任务阻止接管。recover 提供旧桥接清理，文档恢复仍需人工核验，PID 复用或恢复锁残留需人工处理。从零设计已有公开案例，跨页设计系统检索与完整视觉回归仍待实现。
