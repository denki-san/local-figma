## 评分规则

### 当前本地基线进展

2026-09-19 后续：已修正头像、描边和箭头方向；HTML 主说明路径完成关闭/重开、折叠、滚动和模拟操作实点。浏览器计算布局已重建为独立原生画板，含本地卡片主组件，字体、单实例文字编辑和双实例联动验证通过。详细步骤、真实节点及截图保存在本地私有验收记录，公开复现用例待脱敏整理。下段保留首次基线记录，不代表最新状态。

2026-09-19：Design to Code 已从授权原稿只读提取 1622 个可见节点、441 份图像或矢量素材，生成本地 HTML 基线并在浏览器打开。文字使用 HTML 文本，保留节点映射。首次视觉检查发现分组偏移重复叠加、头像遮罩及素材显示问题；分组偏移已调整，其余继续核验。另有 33 个小图形导出失败并保留逐节点记录。当前仅为固定视口视觉基线，尚未完成语义组件、交互、响应式与截图差异验收，不评分为达标。原稿数据与生成物保存在忽略目录，不进入公开仓库。

每个案例满分 10 分：内容与任务正确性 2 分，布局与视觉还原 3 分，可编辑性或代码可维护性 2 分，交互与状态覆盖 2 分，证据和复现步骤 1 分。逐项记录扣分原因，来源及目标截图必须采用相同尺寸与状态。

上线门槛为每项至少 8 分，同时无阻断主要路径的问题。缺失截图、未运行页面、未实际点击或只检查 reactions 的案例保持待验证。HTML 的“1:1”需通过来源对照证明，评分 8 分不等同于像素完全一致。

## 测试与发布边界

真实测试在用户授权的 Untitled 文件独立测试区域进行，保留原设计及参考。每项记录来源、输入、脚本、节点映射、输出、前后截图、实际点击步骤、评分和遗留限制。私有原文与凭证留在本地忽略目录，公开案例使用适合发布的素材及脱敏证据。

五项验收完成后，再复核正式名称、许可证、README、徽章真实性、安装包内容和 GitHub 提交结果。文档与检查器支持五种入口，仅表示流程入口已提供。
