## 已有证据的使用边界

历史基线完整自动回归147/147通过，覆盖CLI、HTTP、插件执行器、证据保存、状态提示和隔离安装；后续改动只做相关局部检查，最新候选源码尚未重新完整回归，须用户确认后才运行。部分测试使用模拟Figma文档API；真实画布证据独立记录在[桌面验收摘要](desktop-acceptance.md)。

公开包边界补充检查已通过：私有验收文档的`test-`与`test_`两种前缀均排除；README引用的公开合成截图随包分发；按实际清单逐一核对Markdown相对链接目标，并拒绝个人主目录和系统临时目录路径。截图仅允许Figma导出器文字标记，不包含EXIF。以上为特定自动检查，完整公开内容与许可证审查仍待完成。

单字段故障恢复、实例文字覆盖、固定布局调整、合成设计与限定原型路径已有局部实证。完整文档自动恢复、多文件与其它系统兼容性仍属于暂缓范围。完整新设计案例质量验收属于本次五场景要求，不能以提供引导代替。

## 交付顺序

1. 完成新P0尚缺的实现与真实稳定性门槛。
2. 完成Code to Design验收，并整理各场景公开复现内容。
3. 补齐名称与许可证决定，检查公开文件不包含真实设计内容、会话凭证或私有执行记录。
4. 从当前源码生成候选包，复测安装与README命令。
5. 提交指定仓库，核对远程文件、实际CI结果和首页链接；保留未覆盖边界。
