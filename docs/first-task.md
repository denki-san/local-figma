# 向 Agent 提任务

把目标 Figma 链接和需求交给能执行本地命令、查看图片的 Agent。你负责提供内容、选择方向和检查成果；Agent 负责安装、连接、整理任务资料和操作 CLI。

## 第一次连接

> 帮我安装并连接 local-figma。目标是【Figma 链接】，我想【需求】。请处理本机依赖和连接；需要我在 Figma 中操作时，请给我具体步骤。

首次按提示在目标文件导入并运行插件。保持桥接终端和插件运行；同一绑定范围内可以直接继续对话，换文件或超出范围时再提供新链接。命令见[快速开始](quickstart.md)。

## 五种任务怎么说

### 已有稿精修

> 请修改已连接稿件中的【具体问题】，范围是【区域】，保留【文字、组件或风格】。先查看现有结构、样式和截图，给我简短方案；确认后局部修改，展示前后截图和检查结果。

### 从零设计

> 请在已连接的空白 Frame 设计【页面】，面向【使用者】，主要任务是【目标】，尺寸是【设备或宽高】。内容来自【文案、数据或文件】，参考【图片或文字方向】。先给两个结构方向让我选，再制作关键区域供我看截图，确认后完成原生可编辑页面。

可以附 2–3 张参考图，说明每张借鉴的布局、字级或组件；也可以用文字描述视觉方向。使用合成占位内容时，请让 Agent 在交付中标注。

### Design to Code

> 请把已连接的【Figma 页面】实现为【目标代码项目】中的可运行页面。保留【文字、素材和关键交互】，按【目标尺寸】对照设计稿与运行页面，交付页面和对照结果。

### Code to Design

> 请把【本地网页地址或代码项目】中的【页面】还原到已连接的 Figma 画板。保留真实内容，重复元素尽量做成本地组件；完成后读回结构、查看截图并核对组件关系。

### 交互原型

> 请在已连接的画板中制作【主要操作路径】，包含【跳转、返回、弹层或状态变化】。完成后实际点击路径，交付原型链接和点击检查结果。

双向转换与复杂交互由 Agent 逐页实现和校正；CLI 提供 Figma 读写与证据能力。资料缺口请 Agent 集中询问影响本次执行的关键问题。

## 交付与异常

Agent 应先读目标并预览，再执行已确认范围内的一次修改；每个任务 ID 都要读取对应结果。完成后展示成果、修改摘要、截图及必要的真实点击检查。等待超时或连接中断时，先查原任务与文档，再决定下一步。

高风险共享定义或大范围修改需要你在插件中亲自确认。效果需要调整时，指出具体区域，让 Agent 根据截图继续局部修改。输出细节见[协议](protocol.md)。
