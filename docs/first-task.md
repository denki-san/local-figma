# 第一次交给 Agent 使用

你负责描述需求、选择方向和检查成果；Agent 负责整理 brief、编写脚本和操作 CLI。使用能执行本地命令、读取图片的 Agent。无需自己编写 JavaScript 或填写 JSON。

## 连接一次

把目标页面、画板或元素的链接直接发给 Agent，并说明需求：

> 帮我安装并连接 local-figma，目标是【Figma 链接】，我要【修改需求】。请帮我处理依赖、准备连接与排查，只把必须由我在 Figma 中完成的操作告诉我。

Agent 在项目目录检查依赖、执行 init 和 connect。首次按它的提示在目标文件导入并运行小插件。无需在另一个窗口填写同一链接。小窗口显示目标、当前选择与连接状态；同一目标的后续修改直接在对话提出。绑定范围内可以选中内容描述修改，换范围再给新链接。首次仍需链接，尚未实现无链接选区绑定。

保持插件运行，面板可以隐藏。原型预览后返回编辑页有助于恢复连接。具体命令由 Agent 查阅 [安装步骤](quickstart.md)。

## 已有稿精修：复制这段话

> 使用本项目的 figma-local CLI 修改我已连接的 Figma 稿。目标问题是【例如正文遮住了底部标签】，只允许修改【目标卡片】，必须保留【完整正文、现有配色和组件】。先读 figma-local help，检查 doctor；通过 inspect、design-system、preview 看结构、已有资源和截图。请替我生成或补充 refine brief，能从稿件确定的信息直接填写，只问影响修改范围的缺口。给我一个简短局部方案，确认后执行；不要改共享组件定义或其他区域。完成后展示前后截图、修改摘要及未验证项。

将方括号内容换成你的需求即可。已有 brief 应增量补充，保留已填信息。普通局部任务无需额外走高风险确认测试。

## 从零设计：复制这段话

在已授权文件中准备空白 Frame，连接它的节点链接。参考图可直接附给 Agent，或提供本地路径。

> 使用本项目的 figma-local CLI，在已连接的空白 Frame 设计【页面类型】，面向【使用者】，主要任务是【用户要完成什么】，尺寸是【设备或宽高】。内容来自【文案、数据或本地文件】。参考是【图片或文字方向】，借鉴【布局、字级、密度等】，避免【不想要的风格】。先检查连接，替我整理 design brief；只问影响设计的必要问题。先给两个简明结构方向让我选择，再确定字体、颜色和间距。先做一个关键区域并给我看截图，确认后完成页面。使用原生可编辑图层，保留完整内容；按本次任务检查长内容、必要状态和主要点击。最后给出画板链接、预览和待确认项。

建议提供 2–3 张参考图，并说明每张借鉴什么。有设计系统时直接提供组件或样式位置。没有图也能开始：说明想要的视觉风格与信息密度，由 Agent 提出方向。参考越明确，视觉迭代通常越有依据；CLI 本身不保证成稿质量。

真实内容尚未准备时，明确允许合成占位内容，并在交付时标注。参考图交给外部模型前，确认你有权使用且接受该模型的数据处理方式。

## Agent 执行约定

1. 在用户指定项目目录运行，先 doctor；连接异常按输出提示处理，避免擅自重启已有任务。
2. guide 生成的文件位于 `.figma-agent/brief-refine.json` 或 `.figma-agent/brief-design.json`。由 Agent 根据对话填写，guide-check 提示缺口；用户选择方向后才记录 acceptedDirection。
3. 每次提交返回任务 ID 后，wait 同一 ID，检查 result.ok。超时继续核查原任务，禁止直接重放创建脚本。
4. 先读取与预览，再执行一个明确区域。绑定页面时先从目录选择实际节点，用 --node 限定目标。脚本只触及授权范围，返回变更节点 ID。
5. 完成后对 run 任务做 diff、validate，另行 preview 并实际查看 PNG。把必要的点击与滚动验收单独记录；检查器的待评审状态由视觉与用户评审补充。
6. 向用户展示成果与差异，技术日志留在本地。只在需要用户决策、无法安全继续或任务完成时打断用户。

## 遇到问题怎么办

- 连接失败：确认终端、插件都开着，回到 Figma 编辑页，再让 Agent 运行 doctor。
- 修改失败或等待超时：先核查当前设计和原任务结果。保留现场，由 Agent 说明已发生什么、下一步改哪里。
- 效果不满意：指出具体区域和预期，让 Agent 根据截图小步修改。完整自动回滚暂未提供。

命令与输出细节由 Agent 查阅 [快速开始](quickstart.md) 和 [输出合同](protocol.md)；用户无需逐条执行内部检查命令。
